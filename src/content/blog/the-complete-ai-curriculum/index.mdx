## Where to Begin: Two Entry Points

Not sure where to start? Donner gives you two doors into the curriculum:

- **Use Products to build Agents → Start with AI Builder (#1).** Create agents in n8n with zero code. Best for non-coders, operators, and founders.
- **Use Agents to build Products → Start with AI Coder (#2).** Build real software with Claude Code and coding agents. Best for developers who want to ship.

Both paths converge on the Core → Agentic → Production trilogy. AI Leader (#3) can be taken anytime — it is a 3.5-hour executive briefing, not a coding course.
