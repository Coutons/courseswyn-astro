## 5 Mistakes to Avoid When Buying Python Courses

1. **Paying full price** — the $199.99 sticker is theater; the real price is $9.99–$12.99.
2. **Buying 5 courses at once** — finish one first; collection without completion is wasted money.
3. **Ignoring the update date** — a Python course untouched since 2022 teaches deprecated patterns.
4. **Trusting 5.0 stars with 50 reviews** — at 10,000+ reviews, ratings cannot be gamed easily.
5. **Skipping projects** — employers hire for GitHub portfolios, not certificates of completion.
